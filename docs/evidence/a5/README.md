# A5 closeout evidence

Captured from the local app at 2560 × 1800 CSS viewport using a fresh headless Chrome profile. The focused browser smoke explicitly resets A4 preview before each theme capture and saves the selected 12 themes plus A4 portrait preview and its print-to-PDF result.

- `wotc.png`, `printer.png`, `lovecraft_*.png`, `dwarves_*.png`, `art_*.png`: one final-state screenshot per selectable theme.
- `a4-portrait.png`: A4 portrait preview at Fit zoom.
- `a4-portrait.pdf`: browser print output; `pdfinfo` reports exactly one 210 × 297 mm page.
- `a4-print-page.png`: rasterized print page for visual inspection.

The historical before-migration screenshots are unavailable. These are final-state captures and are not presented as pixel-diff or historical parity evidence. Contrast is separately checked from computed styles in the focused smoke.
