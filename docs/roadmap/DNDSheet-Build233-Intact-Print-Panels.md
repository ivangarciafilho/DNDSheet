# Build 233 — Keep statblock panels together

Column balancing uses whole panels and tables as break units. A panel that cannot fit in the remaining column space moves forward in reading order. The columns grow when the tallest block requires more height. Section headings stay with the next block where possible.

The focused browser test checks that each long trait, action, and eight-row table has one rectangle in print. The generated landscape PDF keeps the portrait, action and complete table on one A4 page.
