# Build 237 — Statblock riders and spellcasting typography

The statblock groups equal skill scores with matching roll conditions. Spellcasting emphasizes rules terms and quantities, and each Metamagic option has its own indented row.

The editor supports cadence and timing for AC, HP, Speed, Senses and Languages riders. Death Throes and On Damage have dedicated sections. HP groups can independently render on sub-rows. Existing files retain their shared HP split setting as the default.
The typecheck baseline records a reversed literal union order in four existing diagnostics. The diagnostic comparison and count for those entries are preserved.

The final release gate passed all 10 stages.
